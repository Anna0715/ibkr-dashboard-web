# IBKR 投资管理仪表盘 · 公开网页版

保留原站深色与紫色样式、侧栏、卡片、图表、七个栏目和报告日期筛选。可直接访问，无需登录。所有数据均为真实 IBKR 账户快照；此公开版本按账户所有者的明确要求发布，未使用示例数据。账户编号、登录凭据、密钥及后台配置不在本仓库中。

网页由 GitHub Pages 托管，从 main 分支根目录发布；原版 styles.css 保持逐字一致。页面访问和刷新仅加载既有快照，不执行交易、不查询券商、不修改账户。

报告增加真实数据图解：历史账户与基准趋势、持仓分布、盈亏与日损益柱状图、证券多周期涨跌对比、订单状态和研究覆盖。历史图表来自对应日报表格，账户快照图表来自同一快照；缺失值保留缺口。原文本、表格和来源链接完整保留。点击正文、持仓表、观察列表或图表中的股票代码，会切换到该股票的主分析并定位、高亮；跨归档日期时明确提示日期。GOOG仅共享GOOGL的公司分析，价格和代码仍分开。

公开文件为 HTML/CSS/JavaScript 和 data.json、market.json、reports.json，不依赖 Node、Render、Supabase 或登录接口。既有 ChatGPT 云端日报、周报任务通过 IBKR 与 GitHub 连接生成报告，按照 [TASKS.md](./TASKS.md) 追加历史、提交文件并核验线上版本。scripts/report-pipeline.mjs 校验七栏目、日期、来源、缺口和公开数据清洗，保留同日修订及完整历史；重复内容重试不新增。任务说明配置成功与实际自动发布完成必须分别核验；首次完整自动运行的状态以任务结果为准。网页自身不触发任务，手机推送依赖 ChatGPT 账户与系统通知权限。

# IBKR 投资管理仪表盘 · 公开网页版

保留原站深色与紫色样式、侧栏、卡片、图表、七个栏目和报告日期筛选。可直接访问，无需登录。所有数据均为真实 IBKR 账户快照；此公开版本按账户所有者的明确要求发布，未使用示例数据。账户编号、登录凭据、密钥及后台配置不在本仓库中。

网页由 GitHub Pages 托管，从 main 分支根目录发布；原版 styles.css 保持逐字一致。页面访问和刷新仅加载既有快照，不执行交易、不查询券商、不修改账户。

账户读取时间：2026-10-13 14:47–14:50 日本时间。绩效底层日期截至 2026-10-09；市场图表保存数据截至 2026-10-08。2026-10-12 收盘报告已从原会话完整附件恢复，报告发布日为 2026-10-13、采集截止为 11:05 新加坡时间。七栏目包含 90 个证券分析单元、完整市场七部分、原报告表格和来源链接；行情、研究与条件方案仍属当时历史内容，本次没有重新核验。原报告仍缺 48 个证券的本期行情，因此覆盖状态保持 partial。archive/2026-10-12.html 保留完整原日报及历史账户曲线，并注明历史归档状态。默认显示全部已归档日期的日报；分析栏目先呈现保存的分析，再显示较新账户快照的覆盖状态。周总结通过报告类型单独查看；选择全部报告时只附周覆盖清单，避免重复正文。周总结仅根据已有日报生成，覆盖不足时明确标记。

公开文件为 HTML/CSS/JavaScript 和 data.json、market.json、reports.json，不依赖 Node、Render、Supabase 或登录接口。之后更新快照需同步这些文件；日报与周报自动更新尚未配置。
